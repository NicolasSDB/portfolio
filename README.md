## 📋 Visão Geral

Este repositório contém o código-fonte do meu portfólio pessoal interativo. O projeto foi desenvolvido focado em ser leve, direto e acessível, utilizando apenas tecnologias nativas (Vanilla) da web, sem a necessidade de frameworks pesados no front-end. 

Ele funciona como um currículo vivo, onde demonstro minha trajetória profissional, meus projetos (como o Ecossistema NTEC) e o meu cuidado com a experiência do usuário e otimização de código.

## ✨ Principais Recursos

A interface foi pensada para ser agradável e funcional:

* **Sistema Multi-idioma (i18n):** Alternância instantânea entre Português e Inglês, salvando a preferência do usuário.
* **Tema Claro/Escuro:** Troca de temas suave utilizando variáveis nativas do CSS.
* **Navegação Fluida:** Barra de progresso de leitura e destaque dinâmico da seção ativa no menu.
* **Interatividade:** Cards com leve efeito 3D (Tilt) no desktop, janelas modais para detalhamento de projetos e carrossel de fotos de eventos.

## 🚀 Tecnologias Utilizadas no Projeto

O site foi construído 100% "na mão", priorizando performance e código limpo:

* ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5:** Foco em semântica e estruturação limpa.
* ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) **CSS3:** Variáveis nativas, Flexbox/Grid e animações leves.
* ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) **Vanilla JavaScript (ES6+):** Lógica de interface feita do zero, sem dependências de terceiros (sem jQuery ou bibliotecas externas).

## ⚡ Desempenho e UX

Tive um cuidado especial para que o site não travasse ou ficasse pesado, mesmo em computadores ou celulares mais antigos. Para isso, apliquei algumas boas práticas:
* Uso de aceleração de hardware (GPU) para as animações e efeitos visuais.
* Otimização dos eventos de rolagem (scroll) e movimento do mouse com `requestAnimationFrame`, evitando a sobrecarga e engasgos no navegador.
